# About xAquaticRiskAnalysis

**xAquaticRiskAnalysis (xARA)** is a standalone web-based analysis tool for the open-source **xlandscape** Landscape-scale Ecological Risk Assessment (LeRA) framework.

## Purpose

xAquaticRiskAnalysis provides:

- **Rapid analysis** of aquatic toxicity and risk from xAquaticRisk simulations
- **Interactive visualization** of predicted environmental concentrations (PEC) and effects across stream reaches
- **Publication-ready output** (figures, tables, data files) for risk assessment reports
- **Zero-installation deployment** – bundled Python runtime; works on any Windows machine

## Key Features

✓ **xcopy-ready** – No external dependencies or system installation required  
✓ **Automated self-repair** – Auto-bootstraps embedded Python runtime on first launch  
✓ **Real-time analysis** – Submits jobs via web UI with live progress logging  
✓ **Flexible output** – Excel tables, PNG figures, JSON/CSV raw data  
✓ **Multi-user via LAN** – Run on shared server for team collaboration  
✓ **Scriptable API** – HTTP endpoints for automation and integration  

## Part of xlandscape

xAquaticRiskAnalysis is one component of the open-source **xlandscape** framework:

- **[xAquaticRisk](https://github.com/xlandscape/xAquaticRisk)** – Simulation engine for aquatic risk assessment
- **xAquaticRiskAnalysis** – Analysis and reporting tool (this repository)
- **[SETAC-Training](https://github.com/xlandscape/SETAC-Training)** – Educational materials and case studies

All components are developed by the **xlandscape team** at Agroecology, University of Bonn, Germany.
